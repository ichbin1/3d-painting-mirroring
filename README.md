# Зеркалирование фигуры от углов

Учебное приложение на **Python + Tkinter**, которое строит орнамент из произвольного
многоугольника: фигура зеркалится относительно каждой своей вершины, а одноимённые углы
соседних копий соединяются линиями. Дополнительно реализован второй, более простой
алгоритм — копирование фигуры со смещением по сетке.

Проект не использует сторонних библиотек: только стандартная библиотека Python
(`tkinter`, `math`).

## Возможности

- Рисование произвольного многоугольника кликами по сетке с привязкой к половине клетки.
- Центральная симметрия («отражение») фигуры относительно **каждого** её угла.
- Автоматическая сортировка копий: начиная с самой верхней, далее по часовой стрелке.
- Соединение одноимённых углов соседних копий по кругу (замыкание орнамента).
- Копирование фигуры со смещением на заданное число клеток и соединение углов
  между соседними копиями.
- Режим «без задних граней»: у каждой копии показывается только «окно» из нескольких
  последовательных рёбер, что имитирует видимую часть поверхности.
- Опция удаления соединительных линий, пересекающих видимые грани (геометрический тест
  на собственное пересечение отрезков).
- Подписи вершин и рёбер, включаемые отдельным флажком.
- Масштабирование колесом мыши (с сохранением точки под курсором), панорамирование
  средней кнопкой, кнопки «+», «−» и «Сброс вида».
- Двухуровневая сетка: основные линии по клеткам и вспомогательные — по половинам клеток
  (появляются при достаточном масштабе).

## Требования и запуск

**Требования**

- Python 3.8 или новее (проект проверен на Python 3.14).
- Модуль `tkinter` — входит в стандартную поставку Python для Windows и macOS.
  В Linux его может потребоваться установить отдельно:

  ```bash
  # Debian / Ubuntu
  sudo apt install python3-tk
  # Fedora
  sudo dnf install python3-tkinter
  # Arch
  sudo pacman -S tk
  ```

**Запуск**

```bash
git clone <URL-репозитория>
cd <папка-репозитория>
python 3d_painting.py
```

На Windows с установленным лаунчером Python:

```powershell
py 3d_painting.py
```

Установка зависимостей не требуется — `pip install` не нужен.

**Быстрый старт**

1. Поставьте левой кнопкой мыши 4–6 точек — это углы фигуры.
2. Нажмите «Замкнуть фигуру» (или правую кнопку мыши).
3. Нажмите «Алгоритм 1: отражения» — появятся копии фигуры и соединительные линии.
4. Включите «Без задних граней» и подвигайте ползунок «Видимых граней»,
   чтобы получить эффект объёмной поверхности.
5. «Алгоритм 2: смещение» — альтернативный способ построения ковра из копий.

## Управление

| Действие | Результат |
| --- | --- |
| **ЛКМ** по холсту | Добавить угол фигуры (с привязкой к 0.5 клетки) |
| **ПКМ** по холсту | Замкнуть фигуру (нужно минимум 3 точки) |
| **Колесо мыши** | Масштаб относительно курсора |
| **СКМ + движение** | Панорамирование холста |
| Кнопки «+» / «−» | Масштаб относительно центра холста |
| «Сброс вида» | Масштаб 100 %, начало координат в центре |

Клавиатурных сокращений нет: всё управление выполняется мышью и кнопками панели.

## Панель управления

Блок **«Управление»**

| Элемент | Назначение |
| --- | --- |
| «Замкнуть фигуру» | Замыкает контур: последняя точка соединяется с первой |
| «Алгоритм 1: отражения» | Строит копии фигуры центральной симметрией от каждого угла |
| «Алгоритм 2: смещение» | Строит копии фигуры, сдвинутые влево-вниз |
| «Смещение, кл.» | Шаг сдвига в клетках (1–50, по умолчанию 3) |
| «Копий» | Количество копий для алгоритма 2 (1–50, по умолчанию 1) |
| «Удалить последнюю точку» | Убирает последнюю точку; если фигура замкнута — сначала снимает замыкание и сбрасывает построения |
| «Очистить всё» | Полностью очищает холст и все построения |

Блок **«Вид»**

| Элемент | Назначение |
| --- | --- |
| «−» / «+» | Уменьшение / увеличение масштаба в 1.2 раза |
| «Сброс вида» | Масштаб 100 % и центрирование |
| «Масштаб: N %» | Текущий масштаб (100 % = 40 пикселей на клетку) |

Блок **«Просмотр»**

| Элемент | Назначение |
| --- | --- |
| «Без задних граней» | Включает режим частичной видимости граней копий |
| «Удалять пересекающиеся грани» | Доступен только вместе с предыдущим флажком: убирает соединительные линии, пересекающие видимые рёбра |
| «Показывать обозначения» | Подписи вершин и рёбер |
| «Видимых граней» | Ползунок 1–20: сколько последовательных рёбер каждой копии считать видимыми |

Внизу панели выводится памятка по управлению мышью.

## Режимы просмотра

**Обычный режим.** Все копии рисуются целиком: контур зелёного цвета и все вершины
оранжевыми точками. Соединительные линии (фиолетовые) строятся между всеми
одноимёнными углами соседних копий `k` и `k+1` (по кругу).

**«Без задних граней».** Для копии с номером `k` (номер определяется порядком сортировки)
видимыми считаются `w` подряд идущих рёбер, начиная с ребра `k`:

```
E_k = { k, k+1, …, k+w-1 } (mod n)
V_k = { k, k+1, …, k+w   } (mod n)
```

где `n` — число углов фигуры, а `w` — значение ползунка «Видимых граней».
Проводятся только рёбра из `E_k`, вершины рисуются только из `V_k`,
а соединительные линии — только между вершинами, видимыми у **обеих** соседних копий
(`V_k ∩ V_(k+1)`). За счёт этого орнамент выглядит как «гармошка» из видимых полос
поверхности. Если `w >= n`, режим фактически отключается — показываются все грани.

**«Удалять пересекающиеся грани».** Для каждой потенциальной соединительной линии
выполняется проверка на собственное пересечение с уже видимыми рёбрами копий
(тест ориентации четырёх троек точек). Линии, пересекающие рёбра во внутренних точках,
не рисуются. Касание концами или вершинами пересечением не считается.

## Алгоритм 1 — отражения

Кнопка **«Алгоритм 1: отражения»** требует замкнутой фигуры минимум из трёх точек.

1. Вычисляется центр масс исходной фигуры:

   ```
   C = (1/n) · Σ P_i
   ```

2. Для каждого угла `P_i` строится центрально-симметричная копия всей фигуры
   относительно этого угла:

   ```
   Q' = 2·P_i − Q   для каждой вершины Q исходной фигуры
   ```

   То есть `P_i` служит центром симметрии: сам угол остаётся на месте,
   остальные вершины «отражаются» через него.

3. Копии сортируются по полярному углу их центров вокруг центра масс — начиная
   с самой верхней, далее по часовой стрелке:

   ```
   θ_i = ( atan2(P_i.y − C.y, P_i.x − C.x) + π/2 ) mod 2π
   ```

   Ось Y на экране направлена вниз, поэтому возрастание `θ` соответствует
   движению по часовой стрелке.

4. Углы с одинаковыми номерами у соседних копий соединяются по кругу:

   ```
   для k = 0 … m−1:  соединить mirrored[k][j] и mirrored[(k+1) mod m][j]
   ```

   где `m` — число копий (равно числу углов фигуры), `j` — номер угла.

5. Верхняя граница ползунка «Видимых граней» подстраивается под число углов `n`.

Результат алгоритма 2 при этом сбрасывается — два построения одновременно
не отображаются.

## Алгоритм 2 — смещение

Кнопка **«Алгоритм 2: смещение»** строит «ковёр» из копий фигуры.

- Шаг сдвига `s` задаётся полем «Смещение, кл.» (в клетках сетки).
- Количество копий `m` задаётся полем «Копий».
- Каждая следующая копия смещается ещё на один шаг **влево и вниз**.
  Поскольку ось Y на экране направлена вниз, вектор смещения равен `(−s, +s)`:

  ```
  Q_k = Q + k·(−s, +s),  k = 1 … m
  ```

- Одноимённые углы соединяются между соседними копиями:

  ```
  исходная → копия 1 → копия 2 → … → копия m
  ```

  то есть каждый угол `j` предыдущей фигуры соединяется с углом `j` следующей.

Некорректные значения (не целые, нулевые или отрицательные) приводят к предупреждению
и не выполняют построение. Результат алгоритма 1 при запуске сбрасывается.

## Условные обозначения на холсте

| Цвет / элемент | Что означает |
| --- | --- |
| Голубые линии | Сетка: 1 клетка = 1 мировая единица |
| Бледно-голубые линии | Половинки клеток (при масштабе ≥ 18 px/клетку) |
| Синяя линия | Контур исходной фигуры |
| Красные точки + подписи | Углы исходной фигуры (0, 1, 2, …) |
| Зелёный контур | Копия фигуры |
| Жёлтые круги | Центры отражения (углы, относительно которых зеркалили) |
| Оранжевые точки | Вершины копий |
| Фиолетовые линии | Соединительные линии одноимённых углов |
| Подписи `e0`, `e1`, … | Номера рёбер копии (смещены наружу от центра фигуры) |

## Архитектура кода

Приложение построено на одном классе `GridApp`, который хранит состояние и
перерисовывает холст целиком при каждом изменении.

**Состояние**

| Поле | Назначение |
| --- | --- |
| `points` | Углы исходной фигуры в мировых координатах |
| `finished` | Замкнут ли контур |
| `mirrored` | Копии, полученные отражениями (список многоугольников) |
| `mirror_centers` | Центры отражений в порядке сортировки |
| `connections` | Пары точек для соединительных линий алгоритма 1 |
| `offset_copies` | Копии со смещением |
| `offset_connections` | Пары одноимённых углов для алгоритма 2 |
| `scale`, `ox`, `oy` | Масштаб и смещение мировых координат на экране |

**Основные методы**

| Метод | Назначение |
| --- | --- |
| `world_to_screen`, `screen_to_world` | Преобразование координат |
| `_snap` | Привязка точки к сетке с шагом 0.5 |
| `_segments_properly_intersect` | Тест собственного пересечения двух отрезков |
| `reset_view`, `zoom_at`, `zoom_at_center`, `update_scale_label` | Управление видом |
| `on_wheel`, `start_pan`, `do_pan` | Обработка колеса и панорамирования |
| `_draw_grid` | Отрисовка сетки и половинных линий |
| `on_click`, `on_right`, `finish_polygon`, `undo`, `clear_all` | Ввод и правка фигуры |
| `_visible_sets` | Расчёт видимых рёбер и вершин для режима «без задних граней» |
| `_on_front_only_toggle` | Включение и блокировка опции пересечений |
| `redraw` | Полная перерисовка холста |
| `run_algorithm`, `run_offset_algorithm` | Два алгоритма построения |

**Принципы**

- Вся геометрия хранится в «мировых» координатах (клетках), экранные координаты
  вычисляются при отрисовке — поэтому зум и панорамирование не искажают модель.
- Элементы холста помечаются тегами `grid` и `draw`; при перерисовке удаляются
  только элементы этих тегов, что упрощает полную перерисовку без мигания.
- Точки ввода привязываются к сетке `round(x·2)/2`, поэтому все углы лежат
  на целых или половинных клетках.
- Проверка пересечений выполняется только в режиме «без задних граней», чтобы
  не замедлять обычную отрисовку на сложных фигурах.

## Ограничения и особенности

- Несмотря на имя файла `3d_painting.py`, приложение **двумерное**: «объёмность»
  достигается только визуальным приёмом с видимыми гранями, реальной 3D-геометрии,
  перспективы и освещения нет.
- Оба алгоритма взаимоисключающие: запуск одного сбрасывает результат другого.
- Размер холста фиксирован (1100 × 760); при изменении размера окна холст
  растягивается, но сетка пересчитывается по исходным размерам.
- Фигура после замыкания не редактируется: чтобы изменить контур, снимите замыкание
  кнопкой «Удалить последнюю точку» и нарисуйте его заново.
- Соединительные линии строятся только между соседними копиями в порядке сортировки;
  диагональные и «дальние» связи не создаются.
- При большом числе углов и включённой проверке пересечений отрисовка может
  замедляться: проверка выполняется для каждой пары «линия — видимое ребро».
